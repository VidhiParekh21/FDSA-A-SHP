Doubts Faced During Coding – Practical 3
How to swap two elements?
→ Use a temporary variable to exchange their values.
How to find the smallest element in Selection Sort?
→ Compare each element and store its index in min.
How to insert an element in Insertion Sort?
→ Shift larger elements to the right and place the element in its correct position.
How to compare adjacent elements in Bubble Sort?
→ Compare a[j] and a[j + 1] and swap if needed.
Why use different arrays for each sorting method?
→ To apply all three algorithms to the same original data.
